[Agent Skills](https://agentskills.io/home) 是可移植的指令集合，为 AI 编程助手提供完成特定任务所需的领域知识。对于 MCP 开发，它们将部署模式、工具设计模式、身份验证等设计决策编码为指引，让智能体能够深入了解你的使用场景，并生成合适的服务器骨架。

## 可用技能

一组可供参考的 MCP 开发技能，以 [`mcp-server-dev` 插件](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev)的形式提供。其中包含三个相互配合的技能：

| 技能 | 用途 |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| `build-mcp-server` | 入口技能。深入了解使用场景，选择部署模式与工具设计模式，并转交给专门技能。 |
| `build-mcp-app` | 添加可在聊天中内联呈现的交互式 UI 组件，例如表单、选择器和仪表盘。 |
| `build-mcpb` | 将本地 stdio 服务器与运行时一起打包，让用户无需安装 Node 或 Python 即可使用。 |

每个技能都包含一个 `SKILL.md` 文件，以及一个存放辅助材料的 `references/` 文件夹，包括身份验证流程、工具设计模式、组件模板和清单 Schema，供智能体按需读取。这些文件遵循开放格式，适用于任何实现了该标准的智能体。例如，在 Claude Code 中可以这样安装：

```bash
/plugin marketplace add anthropics/claude-plugins-official
/plugin install mcp-server-dev
```

对于其他智能体，请查看其技能或扩展目录，或将[技能目录](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/mcp-server-dev/skills)（`SKILL.md` 加 `references/`）克隆到相应的技能存放位置。

## 开始构建

安装技能后，请智能体帮助你构建 MCP Server。入口技能会由自然语言请求触发，也可以使用该智能体的技能调用语法直接调用。

编写代码之前，技能会先进行简短的需求探索，通常会询问：

- **连接什么** — 云端 API、本地进程、文件系统或硬件
- **谁来使用** — 仅你自己、你的团队，或所有安装者
- **操作范围有多大** — 少量操作，还是封装一个大型 API
- **用户交互需求** — 纯文本结果、通过[信息征询](/specification/2026-07-28/client/elicitation)提供结构化输入，或丰富的 UI 组件
- **上游身份验证** — API Key、OAuth 2.0，或无需验证

如果你的初始请求已经包含这些信息，智能体会直接进入方案建议阶段。

## 部署路径

根据需求探索结果，技能会推荐以下四条路径之一，并生成相应骨架：

**远程 [Streamable HTTP](/specification/2026-07-28/basic/transports/streamable-http)** 是封装云端 API 时的默认选择。用户无需安装，一次部署即可服务所有用户；服务器能够处理重定向并存储令牌，OAuth 流程也能正常运作。参考技能包含 Cloudflare Workers，以及可移植的 Express/FastMCP 配置骨架。

**[MCP Apps](/extensions/apps/overview)** 通过可在聊天中呈现的交互式组件扩展服务器，例如可搜索的选择器、图表和实时仪表盘。当[信息征询](/specification/2026-07-28/client/elicitation)的扁平表单限制无法满足需求时，技能会转交给 `build-mcp-app`。

**[MCP Bundles（MCPB）](https://github.com/modelcontextprotocol/mcpb)** 将本地服务器及其运行时打包为单个 `.mcpb` 归档文件，让用户无需配置 Node 或 Python 即可安装。当服务器必须操作用户机器，例如读取本地文件、驱动桌面应用或访问 localhost 服务时，应选择这条路径。技能会转交给 `build-mcpb`。

**本地 [stdio](/specification/2026-07-28/basic/transports/stdio)** 仍适合原型开发；准备分发时，也有明确的升级路径，可改用 MCPB。
