远程 MCP Server 将 AI 应用的能力扩展到本地环境之外，使其能够访问互联网上的工具、服务和数据源。连接远程 MCP Server 后，AI 助手可以实时访问外部资源，从实用工具转变为掌握充分信息、能够处理复杂多步骤项目的协作伙伴。

如今，许多客户端已经支持远程 MCP Server，带来了丰富的集成可能。本指南以支持 MCP 的众多客户端之一 [Claude](https://claude.ai/) 为例，演示如何连接远程 MCP Server。虽然这里主要介绍 Claude 通过自定义连接器实现的集成方式，但相关概念同样适用于其他兼容 MCP 的客户端。

## 理解远程 MCP Server

远程 MCP Server 与本地 MCP Server 的工作方式类似，但部署在互联网上，而非你的本地机器。它们提供工具、提示模板和资源，供 Claude 代表你完成任务。这些服务器可以集成项目管理工具、文档系统、代码仓库，以及任何其他提供 API 的服务。

远程 MCP Server 的主要优势在于易于访问。本地服务器需要在每台设备上安装和配置，而远程服务器可供任何已联网的 MCP Client 使用。因此，它们非常适合 Web AI 应用、注重易用性的集成，以及需要在服务器端处理任务或进行身份验证的服务。

## 什么是自定义连接器？

自定义连接器是 Claude 与远程 MCP Server 之间的桥梁。它们让 Claude 直接连接对你的工作流最重要的工具和数据源，使其能够在你常用的软件中工作，并结合外部工具提供的完整上下文得出洞见。

使用自定义连接器，你可以：

- [将 Claude 连接到第三方开发者提供的现有远程 MCP Server](https://support.anthropic.com/en/articles/11175166-getting-started-with-custom-connectors-using-remote-mcp)
- [构建自己的远程 MCP Server，连接任意工具](/docs/2026-07-28/develop/build-server)

## 连接远程 MCP Server

将 Claude 连接到远程 MCP Server，需要通过 [Claude 界面](https://claude.ai/)添加自定义连接器。这会在 Claude 与你选择的远程服务器之间建立安全连接。

<Steps>
<Step title="进入连接器设置">
打开 Claude Desktop 或浏览器中的 Claude，然后进入设置页面：

- **桌面端**：使用快捷键 `Ctrl+Comma`，或点击左上角菜单图标 <img src="/images/claude-desktop-hamburger-menu-icon.png" style={{display: 'inline', margin: 0, height: '1.3em', width: 'auto'}} />，将鼠标移到 "File"（文件），然后选择 "Settings"（设置）
- **浏览器**：使用快捷键 `⌘⇧,`（_macOS_），或点击个人资料图标，在菜单中选择 "Settings"（设置）

进入设置页面后，点击侧栏中的 "Connectors"（连接器）。页面会显示当前已配置的连接器，并提供添加新连接器的选项。

</Step>

<Step title="添加自定义连接器">
在连接器部分，点击窗口右上角的 "Add"（添加）按钮，然后在下拉菜单中选择 "Add custom connector"（添加自定义连接器），开始连接流程。要跟随本教程操作，请复制粘贴以下 URL：

```text Example Remote Server
https://example-server.modelcontextprotocol.io/mcp
```

<Frame>
  <img
    src="/images/quickstart-remote/1-add-connector.png"
    alt="Claude 设置中的添加自定义连接器按钮"
  />
</Frame>

随后会出现对话框，提示输入远程 MCP Server 的 URL。该 URL 应由服务器开发者或管理员提供。请输入完整 URL，确保包含正确的协议（https://）和所有必需的路径部分。

<Frame>
  <img
    src="/images/quickstart-remote/2-connect.png"
    alt="输入远程 MCP Server URL 的对话框"
  />
</Frame>

输入 URL 后，点击 "Add"（添加），继续建立连接。

</Step>

<Step title="完成身份验证">
大多数远程 MCP Server 都要求进行身份验证，以确保安全访问资源。具体流程因服务器实现而异，通常使用 OAuth、API Key 或用户名与密码组合。

<Frame>
  <img
    src="/images/quickstart-remote/3-auth.png"
    alt="远程 MCP Server 的身份验证界面"
  />
</Frame>

按照服务器提供的身份验证提示操作。你可能会被重定向到第三方身份验证提供商，也可能在 Claude 内看到一个表单。身份验证完成后，Claude 将与远程服务器建立安全连接。

</Step>

<Step title="访问资源与提示模板">
连接成功后，远程服务器的资源和提示模板就可以在 Claude 对话中使用。点击消息输入区域左下角的 "Add files, connectors, and more /"（添加文件、连接器等）指示图标 <img src="/images/claude-add-files-connectors-and-more.png" style={{display: 'inline', margin: 0, height: '1.3em', width: 'auto'}} />，将鼠标移到 "Connectors"（连接器），再移到 "Add to Example Remote Server"；悬停时会显示附件菜单。

<Frame>
  <img
    src="/images/quickstart-remote/4-select-resources-menu.png"
    alt="显示可用资源的附件菜单"
  />
</Frame>

菜单会列出已连接服务器提供的全部可用资源和提示模板。选择要加入对话的项目。这些资源会为 Claude 提供来自外部工具的上下文和信息。

<Frame>
  <img src="/images/quickstart-remote/5-select-prompts-resources.png" alt="从菜单中选择具体资源和提示模板" />
</Frame>
</Step>

<Step title="配置工具权限">
远程 MCP Server 通常会提供多个能力不同的工具。你可以在连接器设置中配置权限，控制 Claude 可以使用哪些工具，确保其仅执行你明确授权的操作。

<Frame>
  <img
    src="/images/quickstart-remote/6-configure-tools.png"
    alt="工具权限配置界面"
  />
</Frame>

返回连接器设置，点击已经连接的服务器。在这里，你可以根据需要启用或禁用特定工具、设置使用限制，以及配置其他安全参数。

</Step>
</Steps>

## 使用远程 MCP Server 的最佳实践

使用远程 MCP Server 时，可以参考以下建议，获得安全、高效的体验：

**安全考虑**：连接前务必验证远程 MCP Server 的真实性。只连接可信来源的服务器，并审查身份验证过程中请求的权限。授予敏感数据或系统访问权限时应保持谨慎。

**管理多个连接器**：你可以同时连接多个远程 MCP Server。按用途或项目整理连接器，便于管理。定期检查并移除不再使用的连接器，保持工作区整洁、安全。
