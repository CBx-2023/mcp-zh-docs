## 开始使用

各 SDK 提供相同功能，同时遵循各自语言的惯用方式与最佳实践。所有 SDK 均支持：

- 创建提供工具、资源和提示模板的 MCP Server
- 构建能够连接任意 MCP Server 的 MCP Client
- 本地与远程传输协议
- 在保证类型安全的同时遵循协议规范

访问所选语言的 SDK 页面，获取安装说明、文档和示例。
