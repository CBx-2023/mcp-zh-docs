title: 发现

<div id="enable-section-numbers" />

`server/discover` 让客户端能够在发送其他请求之前，查询服务器支持的协议版本、能力及身份信息。服务器**必须**实现该方法。

## 请求

除标准 `_meta` 外，请求不携带其他请求体参数：

```json
{
  "jsonrpc": "2.0",
  "id": "discover-1",
  "method": "server/discover",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientInfo": {
        "name": "ExampleClient",
        "version": "1.0.0"
      },
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
```

## 响应

服务器返回其支持的协议版本、能力与身份信息。该操作支持[缓存](/specification/2026-07-28/server/utilities/caching)。

```json
{
  "jsonrpc": "2.0",
  "id": "discover-1",
  "result": {
    "resultType": "complete",
    "supportedVersions": ["2026-07-28"],
    "capabilities": {
      "tools": {},
      "resources": {}
    },
    "_meta": {
      "io.modelcontextprotocol/serverInfo": {
        "name": "ExampleServer",
        "version": "1.0.0"
      }
    },
    "instructions": "This server provides weather and resource utilities.",
    "ttlMs": 3600000,
    "cacheScope": "public"
  }
}
```

## 何时调用

客户端可以自行决定是否调用 `server/discover`：也可以直接调用任意 RPC，并在服务器不支持请求的版本时处理 [`UnsupportedProtocolVersionError`](/specification/2026-07-28/schema#unsupportedprotocolversionerror)。不过，`server/discover` 在以下两个场景中很有用：

- **展示服务器信息。** 客户端无需调用 `server/discover` 就能使用服务器，但通过一次请求获取服务器身份、能力和支持的版本十分方便。例如，客户端可以根据单个 `server/discover` 响应展示服务器支持的能力，而不必分别发送 `tools/list`、`prompts/list` 和 `resources/list` 请求进行探测。
- **stdio 向后兼容性探测。** stdio 没有逐请求的 HTTP 状态码来驱动回退。对于同时支持现代服务器（使用逐请求 `_meta`）和旧版服务器（使用 `initialize` 握手）的客户端，**应当**先发送 `server/discover`；具体回退规则见 [stdio：向后兼容性](/specification/2026-07-28/basic/transports/stdio#backward-compatibility)。

完整的版本选择流程见[协议版本协商](/specification/2026-07-28/basic/versioning#protocol-version-negotiation)。有关未知方法对应的 HTTP 状态码，请参阅传输章节的[协议版本请求头](/specification/2026-07-28/basic/transports/streamable-http#protocol-version-header)一节。

## 数据类型

### DiscoverResult

发现结果包含：

- `supportedVersions`：服务器支持的协议版本。客户端应从中选择一个用于后续请求。
- `capabilities`：服务器支持的能力，例如工具、资源、提示模板等
- `_meta['io.modelcontextprotocol/serverInfo']`：服务器软件的名称和版本。服务器**应当**包含该字段。
- `instructions`：可选的自然语言指导，帮助 LLM 有效使用该服务器

<Note>
  `serverInfo` 由服务器自行报告，协议不会对其进行验证。该字段用于显示、日志和调试。客户端**不应当**据此改变自身行为，也**不应当**依赖它作出安全决策。
</Note>
