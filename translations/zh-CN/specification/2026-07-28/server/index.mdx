title: 概览
---

服务器提供了通过 MCP 为语言模型补充上下文的基本构件。这些原语让客户端、服务器和语言模型之间能够进行丰富的交互：

- **提示模板**：预定义的模板或指令，用于引导与语言模型的交互
- **资源**：为模型提供额外上下文的结构化数据或内容
- **工具**：让模型能够执行操作或获取信息的可执行函数

各类原语的控制关系可概括如下：

| 原语 | 控制方 | 说明 | 示例 |
| --------- | ---------------------- | -------------------------------------------------- | ------------------------------- |
| 提示模板 | 用户控制 | 用户自主选择调用的交互式模板 | 斜杠命令、菜单选项 |
| 资源 | 应用控制 | 由客户端附加并管理的上下文数据 | 文件内容、Git 历史记录 |
| 工具 | 模型控制 | 提供给 LLM、用于执行操作的函数 | API POST 请求、写入文件 |
